# Extension Icons

You need to create three icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

For testing, you can use simple colored squares or generate icons from any icon generator tool.

Alternatively, you can use an online tool like:
- https://www.favicon-generator.org/
- https://realfavicongenerator.net/

Just upload any image and it will generate all the required sizes.
